# AI 输出评估器

依据任务目标和可观察证据审查 AI 生成内容，帮助用户发现会影响结果的问题并采取针对性改进。

## 功能

- 按用户量表或任务要求检查文本、代码、分析及其他内容。
- 区分可直接判断的问题与需要外部核验的事实主张。
- 按严重程度整理发现，说明证据、影响和可执行的修订建议。
- 在用户要求时提供修订版、检查清单或待核验事项。

## 目录结构

```text
.
├── README.md
└── skills/
    └── ai-output-evaluator/

```

## 安装

将 `skills/ai-output-evaluator` 目录复制到支持 Agent Skills 的宿主所配置的技能目录中，再按该宿主的说明启用或刷新技能。不同宿主的技能目录和启用方式可能不同，请以宿主文档为准。

## 使用示例

```text
请根据以下要求评估这段 AI 输出：
- 受众：刚入职的分析师
- 要求：步骤准确、无未经支持的事实、控制在 500 字内

请先列出问题及影响，再给出修改建议。
```

用户也可以提供评分量表、代码片段、文档或希望重点检查的维度。

## 适用边界

评估不自动等于事实核查或代码测试；只有实际查阅可靠来源或运行检查后，才能声称完成对应验证。高风险领域仍需要合格专业人士审查。不要擅自向第三方发送用户内容，也不要根据有限文本推断作者的敏感属性。对有害或未经授权的内容，应提出降低风险的修改方向，而不是增强其危害能力。
